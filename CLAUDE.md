# CLAUDE.md

Instructions for Claude Code working in this repository.

## Writing or assessing copy

Any time you draft, edit, or review user-facing copy for The State of Play (email templates, on-site copy, social posts, etc.), use the `anthropic-skills:story-drafting` skill to draft/edit and the `anthropic-skills:proofreader` skill to do a final pass before considering it done. Both encode Venkat's non-negotiable editorial rules (no em dashes, no triads, no AI scaffolding, "said" as the only attribution verb, specific numbers over vague ones, etc.) — apply them by default, not only when explicitly asked.
